Ten events. Seven places. Two cities.

The dashboard opens on documented waterlogging locations in Kanpur and Gurugram. Every record keeps its source link, its event date, the rainfall it reported, and what is still unknown about it.

Unknown never becomes zero. Unknown never becomes safe.

A record may carry a city- or district-level rainfall figure, an event window, or qualitative impact rather than a measurement at the named road. Public reports are incomplete — no match is not proof that a place never floods.

02 / The rainfall clock

Drag the clock. Watch the reference move.

Each historical event reports a rainfall figure. The dashboard compares a rainfall amount against it and reclassifies as the value rises. The rain behind this page follows the dial.

  • Below 75%Under the monitor level.
  • 75% and above · MonitorApproaching the reported reference value.
  • 100% and above · High riskAt or beyond the reported reference value.

Illustrative, expressed as a share of the reference value. These levels are the dashboard’s interface heuristics, not validated road-specific thresholds. The separate Python risk engine uses its own configurable ratio (default 0.70); the two are not interchangeable.

05 / How it fits together

Two sources, never blended.

The browser dashboard reads historical records. The Python risk engine tracks rainfall observations against configured roads. Both aim at the same problem, and neither stands in for the other.

06 / Candour

Honesty is part of the design.

  1. i.

    A prototype, not a certified system.

    Garuda Route is not a flood-prediction or emergency-navigation tool. Follow official warnings, road closures and local emergency guidance.

  2. ii.

    Unknown is never zero, and never safe.

    Missing values stay missing. A road without an explicit observation mapping reads as unmapped, and a stale reading is a data-quality state, not evidence the rain has stopped.

  3. iii.

    Live weather is gated, and says so.

    IMD district data needs official permission and issued credentials. Until then the feed shows as unavailable, never as normal, and district rainfall is never presented as a road-level measurement.

  4. iv.

    A flagged route is a signal, not a promise.

    Comparison checks candidate routes against locations the dashboard already knows. Drainage, runoff, elevation and river levels are not modelled.

07 / Begin

Run it in a minute.

Terminal
$ git clone https://github.com/SG4067/garuda-route.git
$ cd garuda-route
$ node backend/server.js
# then open http://127.0.0.1:3000

Node.js 18 or newer. The web server uses built-in modules, so no root-level install is needed. Google Maps and IMD access are configured separately.
